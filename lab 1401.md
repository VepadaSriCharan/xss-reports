# XML External Entity (XXE) Injection in Employee Search Functionality

## Summary

An **XML External Entity (XXE) Injection** vulnerability was identified in the Employee Directory search functionality.

The application accepts employee search parameters through an **XML request body**. The XML parser processes user-controlled XML without properly disabling external entity resolution.

By modifying the intercepted XML request and defining an external entity referencing a local file, it was possible to retrieve the contents of the server's `/etc/passwd` file.

Both the **Employee Name** and **Department** fields were vulnerable to XXE injection.

## Vulnerable URL

https://kzlabs.in/1401.php

## Vulnerable Fields

- Employee Name
- Department


## Payload Used

The following XML external entity declaration was added to the request:

```xml
<!DOCTYPE foo [
  <!ENTITY payload SYSTEM "file:///etc/passwd">
]>
&payload;
```

The resulting XML request contained the external entity definition and entity reference in the user-controlled fields.

## Steps to Reproduce

1. Navigate to:

```text
https://kzlabs.in/1401.php
```

2. Go to the **Employee Directory** search functionality.

3. Enter a normal value in the **Employee Name** and **Department** fields.

4. Submit the search request.

5. Intercept the request using Burp Suite.

6. Observe that the backend sends the search data as XML.

7. Modify the XML request and introduce an external entity declaration:

```xml
<!DOCTYPE foo [
  <!ENTITY payload SYSTEM "file:///etc/passwd">
]>
```

8. Reference the entity from the user-controlled XML field.

9. Send the modified request.

10. Observe the server response.

11. The response contains the contents of `/etc/passwd`, confirming that the XML parser resolved the external entity.

## Impact

The XXE vulnerability allows an attacker to cause the application to read files from the server, resulting in information disclosure. This may expose sensitive configuration files, API keys, application configuration, and other secrets accessible to the application.

## Recommendation
- Disable external entity processing in the XML parser.
- Disable DOCTYPE declarations and external entity resolution where they are not required.
- Use a securely configured XML parser with XXE protections enabled.
- A WAF can provide an additional layer of protection against common XXE payloads.
