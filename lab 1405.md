# XML External Entity (XXE) Injection in Job Application Functionality

## Summary

An **XML External Entity (XXE) Injection** vulnerability was identified in the job application functionality.

The application processes submitted application details using an **XML request body**. By intercepting the request and injecting an external entity into the XML data, it was possible to make the server read and disclose the contents of the local `/etc/passwd` file.

The vulnerability was confirmed by successfully retrieving sensitive local file contents through the XML parser.

## Vulnerable URL

https://kzlabs.in/1405.php

## Vulnerable Field

- Full Name

## Steps to Reproduce

1. Navigate to:

```text
https://kzlabs.in/1405.php
```

2. Go to the **Apply** section.

3. Fill in the application form with normal details.

4. Submit the application.

5. Intercept the request using Burp Suite.

6. Observe that the application data is transmitted to the server in an **XML format**.

7. Modify the XML request and add an external entity declaration referencing `/etc/passwd`.

8. Place the external entity reference in the **Full Name** field.

9. Send the modified request.

10. Observe the server response.

11. The response contains the contents of the `/etc/passwd` file, confirming successful XXE exploitation.

## Payload Used

The following XML external entity declaration was added to the request:

```xml
<!DOCTYPE foo [
  <!ENTITY payload SYSTEM "file:///etc/passwd">
]>
&payload;
```

## Impact

The XXE vulnerability allows an attacker to cause the application to read files from the server, resulting in information disclosure. This may expose sensitive configuration files, API keys, application configuration, and other secrets accessible to the application.

## Recommendation
- Disable external entity processing in the XML parser.
- Disable DOCTYPE declarations and external entity resolution where they are not required.
- Use a securely configured XML parser with XXE protections enabled.
- A WAF can provide an additional layer of protection against common XXE payloads.
