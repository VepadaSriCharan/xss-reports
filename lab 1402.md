# XML External Entity (XXE) Injection

## Summary

An XML External Entity (XXE) Injection vulnerability was identified in the SMS sending functionality.

The application processes the SMS delivery data using XML. By intercepting the XML request and modifying the `operatorId` field with an XXE payload, I was able to retrieve the contents of the server's `/etc/passwd` file.

This confirms that the XML parser is processing attacker-controlled external entities and allowing local file disclosure.

## Vulnerable URL

https://kzlabs.in/1402.php

## Vulnerable Field

`operatorId`

## Steps to Reproduce

1. Open the application.

2. Enter the required SMS details and click the **Send** button.

3. Intercept the request using Burp Suite.

4. Observe that the data is transferred to the server using XML.

5. Locate the `operatorId` field in the XML request.

6. Modify the XML request by adding the following XXE payload:

```xml
<!DOCTYPE foo [
  <!ENTITY payload SYSTEM "file:///etc/passwd">
]>
```

7. Reference the external entity inside the `operatorId` field:

```xml
<operatorId>&payload;</operatorId>
```

8. Forward the modified request to the server.

9. Observe that the server processes the external entity.

10. The contents of `/etc/passwd` are returned in the response.

## Payload Used

```xml
<!DOCTYPE foo [
  <!ENTITY payload SYSTEM "file:///etc/passwd">
]>
<operatorId>&payload;</operatorId>
```

After sending the modified request, the application returned the contents of `/etc/passwd` in the response.

The successful retrieval of `/etc/passwd` confirms that the `operatorId` field is vulnerable to XML External Entity (XXE) Injection and can be abused to read local files from the server.

## Impact

The XXE vulnerability allows an attacker to cause the application to read files from the server, resulting in information disclosure. This may expose sensitive configuration files, API keys, application configuration, and other secrets accessible to the application.

## Recommendation
- Disable external entity processing in the XML parser.
- Disable DOCTYPE declarations and external entity resolution where they are not required.
- Use a securely configured XML parser with XXE protections enabled.
- A WAF can provide an additional layer of protection against common XXE payloads.
