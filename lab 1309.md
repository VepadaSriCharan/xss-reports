# Cross-Site Request Forgery (CSRF) in Account Deletion Functionality

## Summary

A **Cross-Site Request Forgery (CSRF)** vulnerability was identified in the account deletion functionality.

The application allows an authenticated user's account to be deleted through a request that does not contain effective CSRF protection. An attacker can generate a forged request and induce an authenticated victim to execute it using their active session.

The vulnerability was successfully verified by executing the forged request from the victim's authenticated session and confirming that the victim's account was deleted.

## Vulnerable URL

https://kzlabs.in/1309.php?action=account

## Vulnerable Functionality

- Delete My Account & Data

## Steps to Reproduce

1. Log in to the application using an attacker account.

2. Attacker account credentials used:

- Email: john@gmail.com
- Password: john123

3. Navigate to the **My Account** section.

4. Locate the **Delete My Account & Data** functionality.

5. Intercept the account deletion request using Burp Suite.

6. Copy the intercepted request into a CSRF PoC generator.

7. Generate the CSRF Proof of Concept.

8. Log in to the application using the victim account.

9. Victim account credentials used:

- Email: armin@mail.com
- Password: armin123

10. While authenticated as the victim, open the generated CSRF PoC in the victim's browser.

11. The forged request is processed using the victim's authenticated session.

12. Observe that the victim's account is deleted.

13. The application redirects to the login page with the `deleted=1` parameter.

14. Attempt to log in again using the victim's original credentials.

15. The login attempt fails with an **Invalid email or password** message, confirming that the account was successfully deleted.

## Impact

An attacker can force an authenticated victim to delete their account without their knowledge. This can result in permanent loss of the victim's account, order history, saved data, and other account information.

## Recommendation

- Implement a strong, unpredictable CSRF token for account deletion requests.
- Validate the CSRF token server-side for every request.
- Use appropriate `SameSite` cookie attributes.
- Require re-authentication or an additional confirmation before permanently deleting an account.
