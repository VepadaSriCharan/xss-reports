# Local File Inclusion via Path Traversal in Project Resource

## Summary

I identified a Local File Inclusion (LFI) vulnerability in the **PixelVault** application's project resource functionality.

The application uses the `file` parameter to specify the resource that should be loaded when viewing a project. By modifying the value of this parameter with a path traversal sequence and supplying `../../../../etc/passwd`, I was able to access and read the contents of the `/etc/passwd` file directly from the server.

This confirms that the application is allowing user-controlled file paths to be processed without properly restricting access to the intended project resources.

## Vulnerable Parameter

file

## Vulnerable URL

https://kzlabs.in/904.php?file=../../../../etc/passwd

## Steps to Reproduce

1. Open the **PixelVault** application.

2. Navigate to the **Portfolio** section.

3. Click on any project to open its resource.

4. Observe that the URL contains the `file` parameter used to specify the requested resource.

5. Modify the `file` parameter and provide the following payload:

```text
../../../../etc/passwd
```

6. Visit the following URL:

```text
https://kzlabs.in/904.php?file=../../../../etc/passwd
```

7. Observe that the application processes the supplied path traversal sequence.

8. The contents of `/etc/passwd` are returned by the application.

9. The response contains system account information from the underlying server, confirming that local files can be read through the `file` parameter.

## Payload Used

```text
../../../../etc/passwd
```

## Impact

An attacker can read sensitive local files from the server that are accessible to the application's process. Depending on the application's permissions and server configuration, this could expose configuration files, application source code, credentials, environment information, system account information, and other sensitive data.

## Recommendation

- Do not allow users to provide arbitrary filesystem paths.
- Restrict file access to a specific allowlisted directory.
- Ensure the resolved path remains within the intended application directory.
- Reject absolute paths and path traversal sequences where they are not required.
- Deploy a Web Application Firewall (WAF), such as Cloudflare WAF, to help detect and block malicious file-access requests.
