# Cross-Site Request Forgery (CSRF) in 2FA Disable Functionality

## Summary

A **Cross-Site Request Forgery (CSRF)** vulnerability was identified in the Two-Factor Authentication (2FA) disable functionality.

The application allows an authenticated user's 2FA protection to be disabled through a request that does not contain effective CSRF protection. An attacker can capture the legitimate 2FA disable request, generate a CSRF Proof of Concept, and cause an authenticated victim to execute the request using their active session.

The vulnerability was successfully verified by executing the generated CSRF PoC from the victim's authenticated browser session and confirming that the victim's 2FA was disabled.

## Vulnerable URL

https://kzlabs.in/1311.php?action=security

## Vulnerable Functionality

- Disable Two-Factor Authentication (2FA)

## Steps to Reproduce

1. Log in to the application using an attacker account.

2. Navigate to the **Account Settings** section.

3. Locate the **Disable 2FA** functionality.

4. Click on **Disable 2FA**.

5. Intercept the request using Burp Suite.

6. Copy the intercepted request into a CSRF PoC generator.

7. Generate the CSRF Proof of Concept.

8. Log in to the application using the victim account in another browser.

9. While authenticated as the victim, open the generated CSRF PoC link in the victim's browser.

10. The forged request is processed using the victim's authenticated session.

11. Observe that the victim's **2FA is disabled**.

12. This confirms that an attacker can force an authenticated victim to disable their 2FA protection without the victim intentionally performing the action.

## Impact

An attacker can force an authenticated victim to change their password without their knowledge. This may lead to **account takeover** if the attacker knows the password set through the CSRF request.

## Recommendation

- Implement CSRF tokens for password change requests.
- Validate the CSRF token server-side.
- Use appropriate `SameSite` cookie attributes.
- Require the current password or re-authentication before changing the password.
