# XML External Entity (XXE) Injection in SVG File Upload Functionality

## Summary

An **XML External Entity (XXE) Injection** vulnerability was identified in the SVG file upload functionality.

The application accepts SVG files and processes their XML content without properly disabling external entity resolution. By uploading a specially crafted SVG file containing an external entity referencing a local file, it was possible to retrieve and display the contents of the server's `/etc/passwd` file.

## Vulnerable URL

https://kzlabs.in/1403.php

## Vulnerable Functionality

- SVG File Upload
- SVG Preview / Rendering

## Steps to Reproduce

1. Navigate to the Crew Emblem Editor.
2. Create an SVG file containing the XXE payload.
3. Upload the crafted SVG file.
4. Click Upload.
5. Observe the generated SVG preview.
6. The contents of /etc/passwd are displayed in the preview.

## Impact

The XXE vulnerability allows an attacker to cause the application to read files from the server, resulting in information disclosure. This may expose sensitive configuration files, API keys, application configuration, and other secrets accessible to the application.

## Recommendation
- Disable external entity processing in the XML parser.
- Disable DOCTYPE declarations and external entity resolution where they are not required.
- Use a securely configured XML parser with XXE protections enabled.
- A WAF can provide an additional layer of protection against common XXE payloads.
