# XML External Entity (XXE) Injection in Avatar Upload Functionality

## Summary

An **XML External Entity (XXE) Injection** vulnerability was identified in the avatar upload functionality.

The application accepts image uploads and processes the uploaded file using an **XML-based request**. By intercepting the request and injecting an external entity into the XML data, it was possible to make the server read and disclose the contents of the local `/etc/passwd` file.

The XXE payload was injected into the **creator** field of the XML request.

## Vulnerable URL

https://kzlabs.in/1404.php

## Vulnerable Field

- Creator

## Steps to Reproduce

1. Navigate to:

```text
https://kzlabs.in/1404.php
```

2. Go to the **Account Settings** section.

3. Use the **Upload Avatar** functionality and upload a valid JPG image.

4. Intercept the upload request using Burp Suite.

5. Observe that the request is sent to the server using an XML-based format.

6. Modify the XML request by adding an external entity declaration:

```xml
<!DOCTYPE foo [
  <!ENTITY payload SYSTEM "file:///etc/passwd">
]>
```

7. Reference the external entity from the `dc:creator` field:

```xml
<dc:creator>&payload;</dc:creator>
```

8. Send the modified request.

9. Observe the server response.

10. The response contains the contents of `/etc/passwd`, confirming that the XML parser resolved the external entity.

## Payload Used

The following XML external entity declaration was added to the request:

```xml
<!DOCTYPE foo [
  <!ENTITY payload SYSTEM "file:///etc/passwd">
]>
&payload;
```

This confirms that attacker-controlled XML data can cause the server to access and disclose local files.

## Impact

The XXE vulnerability allows an attacker to cause the application to read files from the server, resulting in information disclosure. This may expose sensitive configuration files, API keys, application configuration, and other secrets accessible to the application.

## Recommendation
- Disable external entity processing in the XML parser.
- Disable DOCTYPE declarations and external entity resolution where they are not required.
- Use a securely configured XML parser with XXE protections enabled.
- A WAF can provide an additional layer of protection against common XXE payloads.
