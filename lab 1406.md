# XML External Entity (XXE) Injection in Account Registration Functionality

## Summary

An **XML External Entity (XXE) Injection** vulnerability was identified in the account registration functionality.

The application processes account registration details using an **XML request body**. By intercepting the request and injecting an external entity referencing a local file, it was possible to make the server read and disclose the contents of the `/etc/passwd` file.

The vulnerability was confirmed through the **Full Name** field.

## Vulnerable URL

https://kzlabs.in/1406.php

## Vulnerable Field

- Full Name

## Steps to Reproduce

1. Navigate to:

```text
https://kzlabs.in/1406.php
```

2. Fill in the account registration form with normal details.

3. Click on **Create Account**.

4. Intercept the registration request using Burp Suite.

5. Observe that the application sends the registration data to the server in an **XML format**.

6. Modify the XML request and add an external entity declaration referencing the local `/etc/passwd` file.

7. Place the external entity reference in the **Full Name** field.

8. Send the modified request.

9. Observe the server response.

10. The response contains the contents of `/etc/passwd`, confirming successful XXE exploitation.

## Payload Used

The following XML external entity declaration was added to the request:

```xml
<!DOCTYPE foo [
  <!ENTITY payload SYSTEM "file:///etc/passwd">
]>
&payload;
```

## Impact

The XXE vulnerability allows an attacker to cause the application to read files from the server, resulting in information disclosure. This may expose sensitive configuration files, API keys, application configuration, and other secrets accessible to the application.

## Recommendation
- Disable external entity processing in the XML parser.
- Disable DOCTYPE declarations and external entity resolution where they are not required.
- Use a securely configured XML parser with XXE protections enabled.
- A WAF can provide an additional layer of protection against common XXE payloads.
