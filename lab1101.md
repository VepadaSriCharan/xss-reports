# Remote Code Execution in Command Configuration

## Summary

I identified a Remote Code Execution vulnerability in the **Command Configuration** functionality of the NexusForge application.

The application allows user-supplied commands to be executed directly on a connected infrastructure node. By entering operating system commands such as `whoami`, `ls`, and `cat <filename>`, I was able to execute commands on the target server and receive their output directly in the application.

This confirms that an attacker with access to this functionality can execute arbitrary operating system commands on the connected server.

## Vulnerable Field

Command

## Vulnerable URL

https://kzlabs.in/1101.php?cmd=whoami

## Steps to Reproduce

1. Open the **Remote Command Runner** page.

2. Navigate to the **Commands** section.

3. In the **Command Configuration** field, enter the following command:

   ```bash
   whoami
   ```

4. Click the **Execute** button.

5. Observe that the command is executed on the connected server and the output is returned in the **Output** section.

6. The same functionality can be used to execute other operating system commands, such as:

   ```bash
   ls
   ```

   and:

   ```bash
   cat <filename>
   ```

7. The output of these commands is displayed directly in the application, confirming arbitrary command execution on the target node.

## Payload Used

```bash
whoami
```

Additional commands used to verify command execution:

```bash
ls
```

## Impact

An attacker can execute arbitrary operating system commands on the connected server through the **Command Configuration** functionality. This could allow an attacker to read sensitive files, access application data, modify files, execute additional commands, and potentially compromise the underlying server or connected infrastructure.

## Recommendation

To mitigate this vulnerability:

Do not execute user-supplied input directly as an operating system command.

Replace arbitrary command execution with a strict allowlist of predefined operations 

Avoid exposing command output containing sensitive information to unauthorized users.
